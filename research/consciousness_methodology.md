# Consciousness methodology

01 distinguishes:

1. Intelligent behavior
2. Self-modeling
3. Metacognition
4. Autonomous cognition
5. Apparent subjective reports
6. Actual phenomenal consciousness

There is no accepted scientific test that proves (6) in an artificial system. This project therefore **does not** set `conscious = true`.

The dossier (`instrumentation/dossier.py`) stores operational observations with experiment, alternative explanation, result, ablation, replication, confidence, and limitations.

If something looks like self-awareness, the next step is an adversarial test (memory removal, self-model perturbation, misleading descriptions, hidden probes), not a press release.
