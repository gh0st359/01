# Known limitations

- The sandbox is a compact 2D physical world, not the full sensory richness of a robot.
- Grounded vocabulary is only as large as developmental pairing provides. Early speech is holophrastic or silent. That is intended.
- Imagination uses the learned latent dynamics, which are small and local.
- False-belief competence is a beginning (stored last-visible locations), not a completed ToM theory.
- Phenomenal consciousness is not claimed and is not treated as a binary variable.
- Parallel workers train transferable world-model fragments only. Autobiographical state is not casually merged.
